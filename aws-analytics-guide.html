📖 Key Concepts

Three mental models that unlock the analytics landscape

⏱ Batch Processing vs Stream Processing

Batch = process a big pile of data all at once later. Streaming = process each event the moment it arrives.

DimensionBatchStreaming
Data scopeProcesses a finite chunk of data at restProcesses an unbounded, continuous flow
LatencyMinutes to hoursMilliseconds to seconds
AWS servicesEMR, Glue, AthenaKinesis, MSK
Best forDaily aggregations, ETL, historical analysisReal-time dashboards, anomaly detection, alerting
ExampleProcess yesterday's sales data each nightDetect fraud on every credit card swipe as it happens

📝 Schema-on-Read vs Schema-on-Write

Schema = the structure of your data (column names, types). Do you check that structure when you store the data, or when you query it?

DimensionSchema-on-ReadSchema-on-Write
When schema is appliedAt query timeAt ingestion time
Data validationNone on write — raw data lands as-isData is validated and transformed before storage
AWS servicesAthena, Glue Crawlers (catalog)Redshift, Glue ETL (transforms)
FlexibilityHigh — redefine schema any timeLow — schema changes require migration
Query speedSlower (parse + apply schema each query)Faster (columnar, optimized, pre-sorted)

⚙ Managed Service vs Self-Managed on AWS

Managed = AWS runs the software for you. Self-managed = you install and run the software yourself on AWS servers.

DimensionManagedSelf-Managed (on EC2/EKS)
Patching & upgradesAWS handles itYou handle it
ScalingAuto-scaling or API callManual or custom automation
AWS examplesMSK, OpenSearch, Glue, Athena, Kinesis, QuickSight, RedshiftEMR (you pick instances), self-managed Kafka on EC2
Control vs easeLess control, less ops burdenFull control, more ops burden
Cost tradeoffPremium per-use pricingLower infrastructure cost but higher people cost
